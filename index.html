Hawaii Player 개인정보처리방침

시행일 및 최종 개정일: 2026년 9월 9일

LSH(이하 “운영자”)는 Hawaii Player의 I-Class 강의 재생 관리, 강의 다운로드, Gemini 퀴즈 풀이 및 강의 요약 기능을 제공합니다. 이 방침은 해당 기능에서 처리하는 정보와 이용 목적, 전송 및 보관 방식, 이용자의 권리를 설명합니다.

강의 요약 데이터 안내: 음성과 화면은 사용자의 브라우저에서 강의 데이터를 읽어 추출합니다. 최신 버전은 요약을 위해 전체 영상 파일을 업로드하지 않으며, 사용자의 마이크나 다른 앱 화면을 수집하지 않습니다. 전체 영상 업로드 방식을 사용하는 구버전에서는 영상에 포함된 음성과 화면이 전송될 수 있습니다.

1. 처리하는 정보와 목적

기능 처리 정보 목적 및 처리 위치
Google 로그인 Google/Firebase 계정 식별자, 이메일, 인증 상태 및 인증 토큰 로그인 유지와 이용 자격 확인. Google 인증 서비스, 브라우저 및 운영 서버에서 처리합니다.
이용약관 동의 계정 식별자, 이메일, 약관 버전·내용, 항목별 동의 여부와 동의 시각 동의 확인과 이용 관리. 서버 데이터베이스에 저장합니다.
강의 관리·출석 확인 강의 제목·주소·식별자, 재생 시간, 출석 상태와 인정 기간, 재생 목록 및 설정 I-Class에서 정보를 읽어 브라우저 내 강의 관리에 사용합니다. 출석 목록 자체를 Gemini 분석 대상으로 전송하지 않습니다.
퀴즈 풀이 문제·선택지 텍스트, 문제·선택지 이미지, 문제 식별 정보와 사고 수준 설정 운영 서버를 통해 Google Vertex AI에 전달해 답변과 해설을 생성합니다.
강의 요약 강의 제목, 추출한 음성(AAC 음성을 담은 M4A 파일), 최대 48장의 화면 이미지, 화면 시각, 강의 길이 및 사고 수준 설정 음성은 Google Cloud Storage에 임시 저장하고, 화면 이미지는 별도 이미지 저장소에 보관하지 않고 운영 서버의 분석 요청에 포함합니다. Vertex AI가 이를 분석해 요약을 생성하며, 음성과 화면에 포함된 발언·이름·얼굴·자료도 함께 처리될 수 있습니다.
다운로드·결과 저장 강의 파일, 퀴즈 문제·해설, 생성된 요약 사용자가 저장 기능을 실행하면 사용자 기기에 파일로 저장합니다.
서비스 운영 요청 시각·경로·응답 상태, 오류 코드·메시지, 처리 시간 및 중복 요청 식별값·처리 상태 보안, 장애 대응, 요청 제한 및 중복 분석 방지에 사용합니다. 오류 기록에는 계정 식별자가 포함된 저장소 파일 경로가 나타날 수 있으며, 클라우드 요청 로그에는 IP 주소 등 접속 정보가 포함될 수 있습니다.

I-Class 비밀번호를 별도로 수집하거나 Gemini에 전송하지 않습니다. I-Class 자료를 가져올 때에는 브라우저의 기존 로그인 상태를 이용합니다.

2. 외부 서비스와 데이터 이용

서비스 제공을 위해 Google의 다음 서비스를 이용하며, 각 기능에 필요한 정보를 전송하거나 처리를 위탁합니다.

외부 서비스 처리 업무와 정보 전송 시점·방법
Google 로그인·Firebase Authentication 계정 식별자, 이메일, 인증 정보로 로그인 및 이용 자격 확인 로그인·인증 갱신·계정 확인 시 암호화된 통신으로 전송
Google Cloud Firestore 계정별 이용약관 내용·버전·항목별 동의 여부·시각 보관 및 확인 동의 또는 이용 자격 확인 시 서버가 암호화된 통신으로 처리
Google Cloud Run·Cloud Storage·Vertex AI 제1항의 퀴즈·강의 요약 정보를 처리하여 답변·해설·요약 생성 사용자가 AI 기능을 실행할 때 암호화된 통신으로 전송
Google Cloud Logging 접속·오류·처리 시간 등 운영 기록을 보안 및 장애 대응에 이용 서버 요청과 서비스 운영 과정에서 기록

국외 처리: Google 서비스는 국외에서 정보를 처리할 수 있습니다. Firebase Authentication의 처리 국가는 미국입니다. Cloud Storage·Firestore 등 저장 지역을 선택하는 서비스의 데이터는 해당 리소스에 설정된 지역에 저장됩니다. Vertex AI는 글로벌 엔드포인트를 사용하므로 요청별 처리 국가를 하나로 고정하지 않으며, Google 또는 하위처리업체가 시설을 운영하는 국가에서 처리될 수 있습니다. 저장소의 위치가 국내이더라도 모든 인증·AI 처리가 국내에서 이루어지는 것은 아닙니다.

외부 처리 사업자와 처리 지역에 관한 상세 내용은 Firebase 개인정보 및 처리 지역 안내, Google AI 처리 지역 안내, Google Cloud 하위처리업체 목록에서 확인할 수 있습니다. 관련 문의·철회·삭제 요청은 제6항의 운영자 연락처로 접수할 수 있습니다. 전송되는 항목은 제1항, 보관 및 삭제 조건은 제3항과 같습니다.

이용 제한: 운영자는 개인정보를 판매하거나 맞춤형 광고·광고 타기팅에 이용하지 않습니다. Google API에서 받은 정보는 이 방침에 안내한 기능 제공·개선, 보안 및 운영 목적에 필요한 범위에서만 사용하며, Chrome 웹스토어 사용자 데이터 정책의 제한적 이용 요건을 준수합니다. 이용자가 특정 정보의 열람에 명시적으로 동의한 경우, 보안 대응 또는 법령상 필요한 경우 등을 제외하고 운영자가 강의·문제 내용을 임의로 열람하지 않습니다.

AI 제공자의 처리: 운영자는 분석 데이터를 AI 모델 학습용으로 별도 제공하지 않습니다. Google은 사전 허락이나 지시 없이 Vertex AI 고객 데이터를 모델 학습·미세 조정에 이용하지 않는다고 안내합니다. 다만 성능 개선을 위한 임시 캐시나 보안·남용 탐지 목적의 기록이 적용될 수 있습니다. 세부 조건은 Vertex AI 데이터 이용·보관 안내와 Google Cloud 데이터 처리 부속약정에 따릅니다. 운영 서버에서 음성을 삭제하는 시점에 Google의 모든 처리 기록까지 즉시 삭제된다는 의미는 아닙니다.

3. 보관 및 삭제

  • 로그인·동의 기록: 계정 및 동의 기록은 이용 자격과 동의 내역을 확인하기 위해 보관하며, 계정 탈퇴·삭제 또는 동의 철회 요청 시 본인 확인 후 삭제를 처리합니다. 정기 자동 삭제 기한은 설정되어 있지 않습니다. Firebase 계정과 동의 기록은 별도로 저장되므로, 인증 계정 삭제만으로 동의 기록이나 임시 파일이 모두 자동 삭제되지는 않습니다.
  • 요약용 음성 파일: 요약 성공 후 서버가 삭제를 시도합니다. 서버 오류·시간 초과·요청 중단·삭제 실패로 파일이 남을 수 있습니다. 중복 요청의 재시도 유효 기간은 15분이며, 만료된 요청에 다시 접근하면 해당 파일의 삭제를 시도합니다. 이와 별개로 생성 후 일정 기간이 지나면 모든 잔여 파일을 일괄 삭제하는 규칙은 설정되어 있지 않아, 오류 파일은 운영자가 삭제하기 전까지 남을 수 있습니다. 삭제 요청은 제6항 연락처로 접수할 수 있습니다. 구버전에서 업로드한 전체 영상에도 같은 삭제 원칙을 적용합니다.
  • 삭제된 저장소 파일: Cloud Storage의 기본 복구 보관 기간은 삭제 후 7일입니다. 해당 기간에는 복구 가능한 사본이 남을 수 있으며, 기간이 지나면 복구할 수 없게 됩니다. 이는 파일 생성 후 7일 내 자동 삭제된다는 뜻이 아닙니다. Google Cloud 복구 보관 안내
  • 문제·이미지·AI 결과: 기능 처리와 결과 표시를 위해 브라우저 및 서버 메모리에서 처리합니다. 동일한 요청의 중복 분석을 줄이기 위해 완료된 요약은 서버 메모리에 최대 15분 동안 임시 보관할 수 있습니다. 퀴즈 진행·결과는 브라우저 세션 저장소에도 저장될 수 있습니다. 앱 서버가 별도 문제·요약 결과 데이터베이스에 저장하는 기능은 없지만, 클라우드 서비스의 보관 조건은 별도로 적용됩니다.
  • 기기 내 데이터: 설정과 강의 목록 등은 브라우저 저장소에 보관됩니다. 로그아웃만으로 모든 설정이나 직접 다운로드한 파일이 삭제되지는 않습니다. 다운로드한 파일은 사용자가 직접 삭제할 수 있습니다.
  • 운영 로그: 기본 설정에 따라 일반 애플리케이션·요청·오류 로그는 30일, 관리자 활동·시스템 이벤트 등 필수 감사 로그는 400일 보관 후 만료됩니다. 모든 로그가 동일한 기간 동안 보관되는 것은 아닙니다. Google Cloud 로그 보관 안내

삭제 대상인 전자 기록은 서버·데이터베이스·저장소의 삭제 기능을 이용하여 제거합니다. 백업·복구 사본과 외부 서비스 기록은 해당 서비스의 보관·삭제 절차가 추가로 적용될 수 있습니다. 법령에 따라 보존해야 하는 정보는 해당 근거와 기간에 따라 필요한 범위에서 별도로 보관합니다.

4. 이용자의 선택과 요청

로그인 및 동의 화면에서 내용을 확인하고 이용 여부를 선택할 수 있습니다. 동의 항목은 미리 선택되지 않으며, 이용자가 직접 체크하고 동의 버튼을 눌러야 합니다. 현재 프로그램은 필수 동의 항목에 동의하지 않으면 기능 이용이 제한됩니다. AI 기능을 실행하지 않으면 해당 기능을 위한 문제·음성·화면 분석 요청은 발생하지 않습니다.

개인정보 처리·외부 전송에 동의하지 않으려면 동의하지 않고 프로그램을 사용하지 않거나, 로그인 후 로그아웃하고 확장 프로그램을 제거할 수 있습니다. 기존에 전송된 정보에 대한 처리 중단·삭제·동의 철회 등의 요청 방법은 제6항에 안내합니다.

강의 요약 중에는 중단 버튼으로 추가 처리를 취소할 수 있습니다. 중단 전에 전송된 데이터까지 회수하거나 즉시 삭제한다는 의미는 아닙니다.
